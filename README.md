# DaoQuartz

DaoQuartz: A Quartz-based Distributed Job Scheduler Platform enabling efficient dead-letter-queueing and robust task automation.

DaoQuartz is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- DaoQuartz: A Quartz-based Distributed Job

- and robust task automation

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DaoQuartz.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure DaoQuartz, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
